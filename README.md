# CV Tech Solutions Gateway

Build a modern, production-grade, highly-responsive landing page and multi-section website for "CV TECH SOLUTIONS", an IT Services & Strategic Consulting firm. 

Tech Stack Expectations:

- Framework: React (Next.js App Router or Vite) + TypeScript

- Styling: Tailwind CSS

- Icons: Lucide React

- Components: Shadcn/ui (Cards, Buttons, Dialogs, Tabs, Accordions)

- Animations: Framer Motion (subtle scroll triggers and fade-ins)

Design & Aesthetic Direction:

- Theme: Ultra-modern, clean, and high-tech corporate aesthetic.

- Color Palette: Deep Navy Blue (#0F172A), Slate Blue accent (#2563EB), Cyan/Teal highlight (#06B6D4), Backgrounds in Pure White (#FFFFFF) and Subtle Cool Gray (#F8FAFC). Dark mode togglable.

- Layout: Generous padding, clean grid systems, micro-interactions on hover, subtle glassmorphism effects on header and service cards.

Core Sections & Features to Implement:

1. Navigation Bar (Sticky/Header with Glassmorphism)

   - Logo: "CV TECH SOLUTIONS" with a modern geometric tech icon.

   - Links: Home, Services, Solutions, About Us, Careers, Contact.

   - CTA Button: "Get in Touch" (Primary highlighted button).

2. Hero Section

   - Headline: "Architecting Next-Gen IT Solutions & Strategic Engineering"

   - Subheadline: "We empower enterprises, startups, and modern businesses to innovate, scale, and build resilient digital products with cutting-edge tech stacks."

   - Action Buttons: "Explore Services" (Primary) and "Book a Consultation" (Secondary Outline).

   - Graphic/Visual: An interactive floating 3D/glass-morphic tech stack card showing visual indicators for Cloud, APIs, React, and Data Systems.

3. Core Services Grid (Interactive Cards with Hover Effects)

   - Service 1: Custom Software Engineering (React, Node, Java Spring Boot, Python).

   - Service 2: Cloud Infrastructure & Migration (Scalable architectures, DevOps, security).

   - Service 3: Data Analytics & AI Automation (Data engines, custom pipelines, actionable insights).

   - Service 4: Strategic IT Consulting (Digital transformation, technical roadmap planning).

4. Industry Solutions / Feature Highlights

   - Tabs component filtering solutions for: "Healthcare & HIPAA Compliance", "Luxury & E-commerce", "Enterprise SaaS", and "Early-Stage Startups".

5. Interactive Tech Stack Showcase

   - Sleek badge-based grid or scrolling marquee displaying core technologies: React.js, Next.js, Node.js, Java, Python, PostgreSQL, MongoDB, AWS, Docker, Tailwind CSS.

6. About Us & Company Stats Banner

   - Stats Counter: "100% Client Commitment", "Modern Cloud Standards", "24/7 Reliability".

   - Short snippet highlighting our core ethos: Bridging complex engineering with real business growth.

7. Careers / Internship Portal Section

   - Feature banner: "Join Our Team — Batch 2027 & 2028 Remote Internships".

   - Roles listed: React Full Stack Intern, Java Full Stack Intern, Data Analyst Intern.

   - CTA Button opening a modal: "View Eligibility & Apply" (Mentioning 65%+ academic eligibility criteria & 100% Remote mode).

8. Interactive Contact & Lead Capture Form

   - Input fields: Full Name, Business Email, Phone, Service Needed (Dropdown), Project Budget, and Message.

   - Functional state management showing a "Thank you, we'll reach out within 24 hours" success message upon submission.

9. Footer

   - Comprehensive multi-column layout: Quick Links, Legal & Privacy Policy, Remote Work Policy summary link, LinkedIn Page link, and Copyright notice for CV TECH SOLUTIONS.

Ensure all layout components are 100% mobile, tablet, and desktop responsive with high color contrast for accessibility (WCAG compliant).
